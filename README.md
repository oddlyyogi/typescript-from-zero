# TypeScript from Zero

Code for the **TypeScript from Zero** video series: live-coded, one chapter at a time, using TypeScript 7 on Node 24+.

Every chapter lives in its own folder under `chapters/` and runs on its own. Pick any chapter, `cd` into it and follow its README.

## Requirements

- Node.js 24.12 or newer
- npm 10 or newer
